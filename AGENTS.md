## Коммиты

Пользователь разрешает коммитить в конце каждой осмысленной фазы работы, не
спрашивая отдельно: веха плана, законченная правка, исправление после
печати. Перед коммитом — `npm run check` и `npm run smoke`, как обычно.
Пушить — только по просьбе.
