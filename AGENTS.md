# AGENTS.md — правила для агентов

Рабочие заметки по репозиторию — в `CLAUDE.md`.

## Коммиты

Пользователь разрешает коммитить в конце каждой осмысленной фазы работы, не
спрашивая отдельно: веха плана, законченная правка, исправление после
печати. Перед коммитом — `npm run check` и `npm run smoke`, как обычно.
Пушить — только по просьбе.

## Документация

Пользовательская документация — в `docs/` (оглавление — `docs/README.md`).
Добавили или изменили фичу, параметр, его диапазон, значение по умолчанию
или режим экспорта — в том же коммите обновите соответствующий файл в
`docs/`; для новой крупной фичи заведите свой файл и сошлитесь на него из
`docs/README.md`.
