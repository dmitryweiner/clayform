# CLAUDE.md — рабочие заметки по репозиторию

## План

`PLAN.md` — источник истины по архитектуре и вехам (M0…M8). Решения,
принятые с пользователем, зафиксированы там же в шапке.

## Команды

```bash
npm run check     # tsc + eslint (запрещает `as`-касты) + vitest
npm run smoke     # браузерный смоук; --preview для прод-сборки
npm run build     # прод-сборка → ./docs (GitHub Pages)
```

Golden-тесты пиннят точную геометрию профилей; пересоздавать осознанно:
`UPDATE_GOLDEN=1 npx vitest run tests/golden.test.ts`.

## Инструменты: постоянные скрипты вместо одноразовых

Не писать временные Playwright/Node-скрипты через `cat > tmp.mjs <<EOF` —
это выброшенные токены на каждом цикле. Многоразовая обвязка живёт в
`scripts/lib/harness.mjs`; новые проверки добавлять **флагом к существующему
скрипту**, а не клонировать его.

- `scripts/smoke.mjs` — браузерный смоук. Флаги: `--preview`.
- `scripts/lib/harness.mjs` — разбор флагов, поднятие vite, сбор ошибок консоли.

## Архитектурные инварианты

- `src/geo/` — чистое ядро геометрии, **никогда** не импортирует Three.js
  (та же развязка, что в родственном mathsculpt).
- Ядро считает **в миллиметрах** (в отличие от mathsculpt с относительными
  единицами): у посуды реальные размеры — часть смысла. `encodeSTL` поэтому
  по умолчанию `scale = 1`.
- Ось модели — z, низ изделия в z = 0. Рендер сам поворачивает в y-up.
- Плоскость разъёма формы — XZ (y = 0). Ручка и носик обязаны лежать в ней:
  ручка при x < 0, носик при x > 0.
- CSG (`src/geo/csg.ts`) — WASM manifold-3d. Объекты Manifold не собираются
  GC: всё, что создано, держать в `CsgScope` и звать `dispose()`.
- Тяжёлые сборки уходят в `src/worker/`; главный поток строит превью.
