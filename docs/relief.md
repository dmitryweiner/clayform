# Рельеф: волны и накатка

Рельеф смещает поверхность тела вдоль нормали. Глубины — в миллиметрах.
Рельеф ложится на тело вращения **до** того, как к нему приставляются ручка и
носик, поэтому сами приставные детали остаются гладкими: узор, заходящий на
ручку, не отпустила бы разъёмная форма.

Рельеф бывает трёх видов, их можно сочетать.

## Волна

| Параметр | Диапазон | Что делает |
|---|---|---|
| И на крышке тоже | галочка | волна идёт и по куполу крышки; высота там — доля дуги купола от поля до ножки |
| Куда бежит | по высоте / вокруг оси / по спирали | «по высоте» — кольцевые валики друг над другом; «вокруг оси» — вертикальные рёбра; «по спирали» — наклонные |
| Форма | синус / треугольник / меандр / валики | профиль гребня; «меандр» здесь — прямоугольная волна, «валики» — полукруглые гребни |
| Гребней | 0–64 | сколько гребней по высоте или за оборот |
| Глубина | −20…20 мм | амплитуда; знак переворачивает волну |
| Фаза | −1…1 | сдвиг гребней на долю периода |
| Шаг спирали | −12…12 | только при «по спирали»: на сколько волна поднимается за оборот; шов замыкается, когда «Гребней × Шаг» — целое |
| Зона снизу / сверху | 0–1 | доли высоты, вне которых рельефа нет |
| Растушёвка | 0–0.5 | на какой доле высоты рельеф плавно гаснет у границ зоны |

Если вдавленный рельеф уходит глубже стенки, приложение предупреждает: там
стенка тоньше заданной.

Для литья в разъёмную форму удобнее всего волна «по высоте»: кольцевые
валики форма отпускает свободно. Рёбра и спирали идут под углом к плоскости
разъёма и могут дать поднутрения — анализатор формы об этом скажет.

## Волна волны (2-й порядок)

Вторая волна работает только вместе с первой.

| Параметр | Что делает |
|---|---|
| Как связаны | **плетение** — произведение двух волн (одна вокруг, другая по высоте — корзинка, вафля); **модуляция** — вторая волна гнёт первую |
| Куда бежит, Форма, Гребней, Фаза, Шаг спирали | как у первой волны |
| Гнёт фазу (−1…1) | при модуляции: вторая волна сдвигает гребни первой |
| Гнёт глубину (0–1) | при модуляции: вторая волна то усиливает, то гасит первую |
| И на крышке тоже | действует, только если и первая волна идёт на крышку |

## Накатка роликом

Колесо-штамп, прокатанное по пояску, как на настоящей керамике. До четырёх
полос («+ Полоса»), у каждой свой узор, высота и глубина. За оборот всегда
укладывается целое число оттисков — половинки оттиска на стыке не бывает.
Под полосой написано, сколько оттисков легло и какой у них шаг.

| Параметр | Диапазон | Что делает |
|---|---|---|
| Узор | полоса, верёвочка, греческий меандр, зигзаг, точки, ромбы, насечки, сетка, картинка | рисунок штампа |
| Вид | ключ, ключ в рамке, спираль, крючки, Т-зубцы, П-волна | только у меандра; ширина пояска — высота рисунка |
| Высота пояса | 0–1 | доля высоты, где проходит середина пояска |
| Ширина | 1–200 мм | ширина пояска; она же задаёт размер оттиска |
| Глубина | −8…8 мм | > 0 — выпуклый узор, < 0 — вдавленный |
| Просвет | 0–100 мм | только у одиночных узоров (точки, ромбы, насечки, картинка): расстояние между оттисками; элемент — квадрат в ширину пояска |
| Наклон | −2…2 | наклон рисунка вдоль пояска |
| Картинка, Инверсия | файл | только у узора «картинка»: любое изображение, уменьшенное до 64 px; белое — на всю глубину, «Инверсия» меняет местами рисунок и фон |

Непрерывные узоры (полоса, верёвочка, меандр, зигзаг, сетка) идут
сплошной лентой. У одиночных число оттисков подбирается само, а
округление уходит в просвет, не в размер элемента.

Мелочь мельче шага сетки в превью не видна — для экспорта поднимите
«Детализацию».

У крышки накатка своя — см. [lid.md](lid.md).
